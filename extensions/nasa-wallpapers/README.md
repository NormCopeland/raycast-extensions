# NASA Wallpapers

Browse and set stunning NASA Astronomy Picture of the Day (APOD) images as your desktop wallpaper.

## Features

### Browse NASA Images
- **Grid View**: Beautiful grid layout displaying NASA APOD images
- **Search**: Search by title, description, or date
- **Filters**: 
  - All Images
  - Starred favorites
  - Images only
  - Videos only
- **Sort**: Sort by date (newest/oldest first)
- **Star/Favorite**: Mark your favorite images for quick access

### Image Details
When viewing an image, you'll see:
- High-resolution image preview
- Full description and explanation
- Metadata (date, media type, copyright)
- Direct link to NASA APOD page

### Actions
- **Set as Wallpaper**: Instantly set any image as your desktop wallpaper
- **Download**: Save images to your computer
- **Open in Browser**: View the full-resolution image
- **Star/Unstar**: Save favorites for later
- **Copy**: Copy image URL or title to clipboard

### Random Wallpaper
- Automatically set a random NASA image as wallpaper at intervals
- Option to use only starred images
- Configurable interval (default: 1 hour)
- Background refresh support

## Setup

1. Install the extension
2. (Optional) Get a free NASA API key at [https://api.nasa.gov](https://api.nasa.gov)
3. Enter your API key in preferences, or use the default `DEMO_KEY`

## Commands

### Browse NASA Images
Browse the NASA APOD image gallery with filters and search.

**Keyboard Shortcuts:**
- `⌘ + W` - Set as wallpaper
- `⌘ + S` - Star/unstar image
- `⌘ + O` - Open in browser
- `⌘ + D` - Download image
- `⌘⇧ + D` - Sort by date (newest first)
- `⌘⇧ + A` - Sort by date (oldest first)

### Set Random Wallpaper
Automatically sets a random NASA image as your wallpaper. Can be configured to run at intervals in the background.

**Preferences:**
- **API Key**: Your NASA API key (optional)
- **Starred Images Only**: Only use starred images for random selection
- **Interval**: How often to change wallpaper (configurable in Raycast preferences)

## About NASA APOD

Each day NASA features a different image or photograph of our fascinating universe, along with a brief explanation written by a professional astronomer. This extension brings that beauty directly to your desktop.
